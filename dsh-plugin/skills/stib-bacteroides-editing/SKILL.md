# STIB 拟杆菌编辑 — 新手操作指南

> 本技能服务的是**第一次做拟杆菌编辑的课题组**。他们需要的不是"最优方案"，
> 而是**照着做能出结果、出不了结果知道先查哪里**。

---

## 第 0 步：先读这三条（否则可能白做两周）

这三条是论文与协议**没有突出**、但记录库显示真实发生过的坑。**先讲这三条，再讲流程。**

### ⚠️ 1. ΔdapA 缺陷型供体的血平板必须加 DAP

若用 `S17DMK` / `WM3064` 这类 ΔdapA 供体，**血平板漏加 DAP 会导致转化子为零**。
记录库 2024-03 实测：3 生物学 × 3 技术重复**全部 0 CFU**，事后发现平板没加 DAP。

> **动作**：配平板时在瓶身标注 `+DAP 0.06 g/L`；接合前双人核对一次。
> **代价对比**：核对 10 秒 vs 白做一整批。

### ⚠️ 2. 接合气氛：按菌株决定，不是"未收敛变量"

| 情形 | 气氛 |
|---|---|
| **论文中测试过的耐氧物种**（*B. thetaiotaomicron* / *fragilis* / *vulgatus* / *uniformis* / *ovatus* / *salyersiae*） | **可直接好氧接合**，照 SOP 做即可 |
| **客户菌株耐氧能力未知**（未在论文中测试过的非模式种） | **厌氧（保守）**；或先做一次好氧/厌氧平行对照 |
| **菌群编辑**（SynCom / 粪便菌群） | **厌氧** |

> **动作**：先判断菌株属于哪一类。**不要对耐氧物种做无谓的厌氧操作**，
> 也不要对未知菌株直接照搬好氧写法。

### ⚠️ 3. 骨架 PCR 阳性 = 共整合，**不是**成功

Type V-K 天然经复制型通路转座，会产生夹带载体骨架的共整合。
骨架特异引物（ampR / ori）PCR **应为阴性**。

> **动作**：阳性者划线纯化后传代 2–5 次复检；**持续阳性则弃去该克隆**。
> 不要因为"有插入条带"就判定成功。

## 标准流程（6 步）

### 第 1 步：拿到用户的基因组与目标

问清三件事：
1. **目标物种与菌株**（决定氯霉素浓度：*B. theta* / *B. ovatus* 用 **25 µg/mL**，其他 **12.5 µg/mL**）
2. **要编辑的基因**（敲除？还是插入 cargo？）
3. **用户自己的基因组 FASTA**（非模式菌不在任何公共预置清单里，**必须让用户提供**）

### 第 2 步：生成方案

调用 `stib_plan`，传：
- `accession`（或用本地 FASTA 路径）
- `gene`（目标基因名）
- `motif`（该基因内的一段序列，用于定位）**或** `start`/`end`
- `species`

### 第 3 步：核对脱靶结果（**必做**）

方案 §2 会给出每条候选的全基因组脱靶评估。**必须检查**：

- **高风险脱靶 > 0 的候选已被自动排除**；若仍出现在表里，说明有 bug
- 阈值默认 **≤4 错配，保证不漏检**（6-mer 块 ×3 + 每块 1 替换；已用暴力穷举交叉验证）
- 若用户要求 ≤5 错配：**会显式警示"可能漏检"**，并提示用 Cas-OFFinder 核对

> **不要声称与 Cas-OFFinder 等价。** 本引擎是种子剪枝，可能少报。

### 第 4 步：给出可下单的寡核苷酸与引物

- **sgRNA oligo**：`aaag` + spacer（F）/ `agcc` + spacer 反向互补（R），PAGE 纯化
- **验证引物**：`LE_up_F` / `RE_dn_R`（基因组侧）
- **16S 对照**：27F / 1492R

> ⚠️ **cargo 内部引物与骨架引物需要用户的 cargo/骨架序列**，工具给不出。
> 明确告诉用户这一点，不要含糊过去。
> ⚠️ Tm 是**估算值**，不可直接用作退火温度，首次须梯度 PCR 确认。

### 第 5 步：给出流程与判定点

方案 §5 是分阶段检查清单，§6 是**症状 → 假设 → 最便宜的判别实验**。
把 §6 单独强调一遍 —— 这是 SOP 没有的部分，也是本工具区别于"再读一遍论文"的地方。

### 第 6 步：递上回退面板

方案 §8 是**已验证的 spacer 面板**，含 ✅ 可用 / 🟠 偏弱 / 🔴 **已知失败**。

> **对新手的价值**：首选位点失败时，不要让他从零设计，直接给已验证的备选。
> 🔴 的条目（如 sgRNA47 = 0%、Bv02/Bv03 = 0%）同样宝贵——避免重复别人踩过的坑。

## 关键参数速查

| 项 | 值 |
|---|---|
| PAM | **GTN**（论文写 NGTN，但 Table S2 全部 25 条实测为 GTN） |
| **PAM 优选** | **① GTT**（经验最多）→ **② GTA** → ③ 其他 GTN |
| spacer | 23 nt |
| 插入位点 | PAM 下游 **60–66 bp**（论文菌群章节写 56–63 bp；**一定偏移可接受**） |
| **位点放置** | 基因失活时应在 **CDS 中央 80%**；论文用更严格的**前 1/3 – 2/3** |
| **序列偏好** | TSD 内含 **GCWGC**；TSD 中心 **±5 bp** 偏好 **(A/T)** |
| 方向 | 单向，LE 靠近靶位点（>99%） |
| TSD | 5 bp |
| **构建** | **只做 psh43 系列**（Cas12k–TnsC 融合） |
| 载体 | R6K 自杀载体 → 拟杆菌内不复制，**瞬时递送，通常无需消除** |
| 供体 | *E. coli* S17-1λpir（纯培养）；S17DMK ΔdapA（菌群） |
| 供体 OD | 1:100 转接后 2.5–3 h，OD600 ≈ 0.4（装液 ≤1/5 容器） |
| 受体 OD | 1:100 转接 BHIS，37 °C 厌氧约 6 h，OD600 ≈ 0.8 |
| 接合 | 1:1 各 1 mL → 4000 g 20 min → 100 µL BHIS 重悬 → 血平板中心 |
| 筛选 | Genta **200** µg/mL + Cm（*bt/bo* **25**，其他 **12.5**） |
| 集落出现 | 2–3 天；菊粉 3–4 天；***B. vulgatus* 可延至 7 天** |

**血平板**：BHIS-琼脂 + **8%(v/v) 脱纤维血（马血或绵羊血都可以）**，
厌氧箱内、50 °C 时加。**关键要求是必须无菌、脱纤维** —— 血平板污染会毁掉整批接合。

**BHIS**：BHI 37 g/L + L-半胱氨酸 0.5 g/L + VK3 0.5 mg/L + 氯化血红素 5 mg/L

## 排查：症状 → 先查什么（按成本排序）

| 看到什么 | 诊断顺序 |
|---|---|
| **平板上无菌落** | ① **血平板是否漏加 DAP**（若用 ΔdapA 供体；零成本，先查）② NC 对照是否生长 → 抗生素失效 ③ **接合气氛是否用错**（耐氧物种应用好氧）④ sgRNA/位点 |
| **骨架 PCR 阳性** | 共整合，**不是阳性克隆**。划线纯化传代复检；持续阳性则弃去该克隆重挑。⚠️ **共整合与位点选择是否有因果关系尚不确定**，不要仅凭此断定是位点问题 |
| **junction 两端无条带，野生型也扩不出** | **先怀疑模板与引物，不是构建失败**。换新引物重做 PCR；同时 16S 确认挑到的是目标菌 |
| **16S top hit 与目标种接近** | **不得只看第一条**。*B. thetaiotaomicron* vs *B. faecis* **98.43%**；*P. vulgatus* vs *P. dorei* **97.10%**。看 top-5 分布 |
| **插入位置略偏离 60–66 bp** | **一定偏移可接受**。仅方向敏感/框内插入时需精确核对 |
| **外送样品前** | 核对质粒关键元件（**RBS 曾自发突变需回补**，记录库 2026-02） |
| **慢生长物种 2–3 天没克隆** | *B. vulgatus* 可延至 **7 天**，勿过早判定阴性 |

## 四种设计模式

| 模式 | 工具 | 适用 |
|---|---|---|
| **单基因敲除** | `stib_plan` | 编辑已知基因；GenBank 时**直接给基因名即可** |
| **批量** | `stib_batch` | 一个较宽区间/基因簇内一次给多条候选 |
| **中性位点** | `stib_neutral_sites` | 插入大片段 cargo，找不破坏宿主功能的落点 |
| **cargo 组装** | `stib_cargo_assembly` | 设计 Gibson 引物 + 输出 SnapGene 图谱 |

**基因名不确定时**先调 `stib_find_gene` 查准确名字（需 GenBank 注释）。

⚠️ **纯 FASTA 无法按基因名定位** —— 基因名不在碱基序列里。
遇到只有 FASTA 的用户，让他三选一：换 GenBank / 给一段基因序列（motif）/ 给坐标。

### cargo 插入的两条硬性约束

1. **cargo 必须落在转座子 LE 与 RE 之间。** 放错会破坏末端识别 → 转座失败，
   而 PCR、Gibson、菌落 PCR 全都正常，**直到接合才发现转化子为零**。
2. **cargo 内不得含 BsaI 位点**（GGTCTC / GAGACC）—— 本载体用 BsaI-HF2
   Golden Gate 换 sgRNA，会被切开。

出引物前会硬性校验这两条，不过就停。

### 中性位点的诚实边界

论文中**已验证**的中性位点（Bt05 @157,758 等）价值**高于**工具从序列特征
预测的候选。报告优先列出已验证位点，并明确标注预测项只是候选。

⚠️ `.dna` 经**往返校验**（独立解析器读回比对），但**未在真实 SnapGene 中打开过**。
若打不开，用 `.gb`（SnapGene 原生支持导入）。

## 明确不要做的事

- ❌ **不要预测编辑效率**。已发表数据点太少（约 11 条带效率的位点），
  抽不出具统计意义的模型。硬做只会产出假精度。
- ❌ **不要声称脱靶评估与 Cas-OFFinder 等价**。本引擎是种子剪枝 + 替换枚举
  （≤4 不漏检，>4 失效并会警示）。
- ❌ **不要猜 cargo 的落点**。落点必须由载体文件的 LE/RE 边界确定。
- ❌ **不要把序列偏好当硬性要求**。`GCWGC` / `±5 A/T` 只参与排序。
- ❌ **不要对耐氧物种做无谓的厌氧操作**，也不要对未知菌株照搬好氧写法。
- ❌ **不要声称下游实验已验证**。工具的正确性上限是"忠实于已发表方法与记录库"。
